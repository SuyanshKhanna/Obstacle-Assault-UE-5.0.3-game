# Obstacle-Assault-UE-5.0.3-game
 Obstacle Assault

A third-person obstacle platformer built with **Unreal Engine 5**.  
The goal is to navigate through moving platforms and environmental obstacles to reach the final stage and win.

This project was created as a learning-focused Unreal Engine project, covering core gameplay systems, level design, animation setup, and packaging.

---

##  Gameplay Overview
- Third-person character movement
- Jumping and platform navigation
- Moving platforms and timed obstacles
- Win condition when reaching the final stage
- Simple visual feedback for game completion

##  Features
- Unreal Engine 5 third-person controller
- Custom level with obstacle-based progression
- Blueprint-driven gameplay logic
- Character animation system (retargeted animations)
- Modular platform actors
- Win trigger system

##  How to Run the Project
1. Install **Unreal Engine 5.0.3**
2. Clone or download this repository
3. Open `ObstacleAssault.uproject`
4. Press **Play** in the Unreal Editor

---

## 📦 Packaging
The project can be packaged for Windows using:
File → Package Project → Windows → Windows (64-bit)
